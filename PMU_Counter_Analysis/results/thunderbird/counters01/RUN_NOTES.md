## Event Selection Notes

The Thunderbird profile used the documented Arm-specific raw proxies for L1 read accesses, L1 read refills, L1 writes, last-level reads, and last-level read misses. Generic `cache-references`, `cache-misses`, and `dTLB-load-misses` opened successfully. The selected event names, raw configs, probe logs, and semantic caveats are preserved in `selected_events.json`, `probes/`, and `analysis/event_semantics.csv`.

Thunderbird's last-level events retain the project caveat that the SLC interpretation is firmware/EXTLLC dependent and was not proven as an isolated socket-level SLC boundary by prior 8.3 evidence.
